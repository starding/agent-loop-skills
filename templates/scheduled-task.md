# 定时任务描述模板

把方括号内容替换为实际信息，整段交给 Agent 创建定时任务。

```text
[触发：每个交易日 8:30（香港时间）]，
从 [连接：哪个系统、什么范围] 中，
按 [做法：筛选 / 汇总 / 起草，格式和长度]，
发送到 [确认：我的私聊 / 我的邮箱，不对外发送]。
[边界：不写任何客户信息。]
```

例子：

```text
每个交易日 8:30（香港时间），
从我已连接的邮箱和 Slack 中，读取过去 24 小时与我有关、尚未回复的消息，
按「谁、什么事、需要我做什么、截止时间」整理成一张表，最多 10 行，
发送到我的 Slack 私聊，不对外发送。
不写任何客户姓名、账户或持仓信息。
```
