# 制作本人的写作标准

标准回答的是「什么算好」。写作标准沉淀下来后，Agent 每次起草都按它执行，本人不必每次说明。

## 1. 取样（只读）

- 本人在群聊、频道中发出的消息，最近 1–2 个月，至少 200 条。
- 本人写的文档 3–5 篇。
- **不读私聊**：私聊的语气和对外不同，不作为依据。
- 客户信息、同事姓名只用于理解语境，不写进技能。

## 2. 归纳

逐项归纳，每项附 2–3 条原句作为例子：

1. 语域：书面还是口语、长句还是短句、是否结论先行。
2. 常用词：本人经常用的词和连接词；本人从不用的词。
3. 句式：请人做事怎么写、提出不同意见怎么写、汇报进展怎么写。
4. 格式：是否用编号列表、怎么写日期和时间、中英文混排习惯。
5. 语言：对哪些对象用中文、繁体、英文。
6. 署名：Agent 代写的消息如何注明。

再列出 Agent 常见的 AI 腔（「值得注意的是」「综上所述」、开头客套、结尾祝福），与本人的写法对照。

## 3. 生成技能

生成 `my-writing-style/SKILL.md`，结构：

```markdown
---
name: my-writing-style
description: <本人>的写作标准。代写消息、邮件、文档时先使用。
---
# 总则（一句话）
# 语域
# 用词（用 / 不用 对照表）
# 句式（场景 → 写法 → 原句例子）
# 格式
# 自检清单
```

## 4. 校准

用新技能起草 3 条本人最近真实要发的消息，请本人逐条修改；把修改意见用 loop-retro 的方法写回技能。通常两三轮后稳定。
